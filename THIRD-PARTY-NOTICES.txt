Not included (installed separately by the user)
-----------------------------------------------
Npcap — the packet capture driver used for live capture. Npcap is free for
personal use; its licence does not allow redistribution without an OEM
licence, so Network Monitor links to https://npcap.com instead of bundling it.

Other location databases (.mmdb) — Settings can point at MaxMind GeoLite2,
DB-IP or IPinfo Lite databases instead of the built-in ones, under those
providers' own licences and attribution terms.

Design reference
----------------
The feature set follows the open-source Sniffnet project
(https://github.com/GyulyVGC/sniffnet, MIT / Apache-2.0). Network Monitor is
a separate implementation and contains no Sniffnet source code.
